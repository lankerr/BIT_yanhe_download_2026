# 最高下载速度压测 · 操作手册（周六早晨照此执行）

> 工具：`scripts/bench_maxspeed.py`（2026-09-05 凌晨就位，已通过本地模拟 CDN 端到端自检：
> K=8/16 档实测吞吐与模拟限速的线性比例完全一致，计量管线可信）

---

## 一、压测前 5 分钟检查（很重要）

| 项 | 要求 | 原因 |
|----|------|------|
| 网络 | **校园网**，有条件插网线 | 测的是"我们下载器最高速度"，校内入口才测得出上限 |
| VPN / 代理 | **全部关闭**（Clash/TUN 也关） | 下载器会绕代理直连，但代理会吃掉机器资源与带宽 |
| 电源 | 插电、禁用睡眠 | 中途睡眠 = 数据作废 |
| 磁盘 | 剩余 ≥ 10 GB | 每次 run 下载约 0.8 GB（跑完自动删，但峰值要占住） |
| 时间 | 建议 6:00–7:30 之间跑完 | 早晨网络最干净，也避开上课高峰对服务端的压力 |

## 二、拿 token（1 分钟）

1. 浏览器登录 https://www.yanhekt.cn
2. `F12` → 控制台粘贴：`javascript:alert(JSON.parse(localStorage.auth).token)` 回车
3. 复制弹出的 32 位 token

## 三、一键压测（推荐命令）

在仓库根目录（`BIT_yanhe_download_2026`）打开终端：

```bash
# 标准版：K=16/24/32 三档 × 2 轮交错，约 30–60 分钟
python scripts/bench_maxspeed.py --token <粘贴token> --course 67092 --ks 16 24 32 --trials 2

# 时间紧就用快速版：三档 × 1 轮，约 15–30 分钟
python scripts/bench_maxspeed.py --token <粘贴token> --course 67092 --ks 16 24 32 --trials 1

# 想摸绝对上限（校园网千兆）：加测 48 / 64 档
python scripts/bench_maxspeed.py --token <粘贴token> --course 67092 --ks 16 24 32 48 64 --trials 2
```

说明：
- 课程默认 `67092`（空中目标探测前沿技术，297 段 / ~777 MB，与历史基线同源，数据可直接对比）；
- 想换课程加 `--course <ID> --session-idx <序号>`；
- 命令行贴 token 不方便的话，把 token 存成仓库根目录 `auth.txt`（一行纯 token）后去掉 `--token` 参数即可；
- **中途 Ctrl+C 不会丢数据**：每次 run 结束都会立刻落盘，报告实时更新。

## 四、拿结果（压测结束自动生成）

产物目录：`bench/results/<时间戳>_maxspeed/`

| 文件 | 用途 |
|------|------|
| `report.md` | **交付件**。开头"一句话结论"可直接抄给领导（最高 MB/s、Mbps、一节课最快耗时、相对 5 月基线倍数） |
| `chart.png` | 吞吐曲线 + 各 run 净吞吐柱状图，放 PPT 用 |
| `runs.csv` | 单次明细，Excel 可开（含 p95 段耗时、重试、停滞、熔断） |
| `samples.csv` | 0.5 秒粒度字节采样原始序列 |
| `results.json` | 全部指标机器可读版 |

终端最后也会打印三行 `★` 摘要，直接截图也行。

## 五、结果怎么读

- **最高速度** = 报告"按 K 汇总"表里净吞吐最高的档位；对比 2026-05-29 基线 1.91 MB/s 的倍数自动算好；
- **如果某档触发限流熔断（`breaker_trips > 0`）**：不是失败，是重要发现——说明该档位触到了延河服务端的容忍上限，报告中"可靠性与限流"一节会给出结论，**这本身就是给领导的最有价值数据之一**（我们能测出服务端边界且客户端会自动退避不硬敲）；
- 如果 32/48/64 档速度不再上升甚至下降：正常，说明到了当前网络/CDN 饱和点（历史实验在家用宽带的饱和点是 8–16，校园网更高）。

## 六、常见问题

| 现象 | 处理 |
|------|------|
| `未找到 token` | 按 `--token` / `auth.txt` / `set YHKT_TOKEN=` 三种方式任选其一（脚本会提示） |
| 某次 run `❌` | 看该行 error 列；单次失败不影响其余 run，最后报告自动汇总成功的 |
| 跑到一半想停 | Ctrl+C，已完成的 run 数据都在 |
| 想验证工具是否正常 | `python scripts/bench_maxspeed.py --mock`（本地模拟，不耗流量不碰真实服务器） |
